# לוח 364 — רקע חי לאנדרואיד

אפליקציה עצמאית: מחשבת את התאריך המקראי ואת שעון חנוך **בתוך הטלפון**, ומציגה אותם **בזמן אמת** במסך הנעילה.
בלי אינטרנט, בלי טרמוקס ובלי צילומי מסך.

## מה מוצג במסך הנעילה
מתחת לשעון ולתאריך של סמסונג, מעל תמונת הרקע שבחרת:
- **שעון חנוך:**
  - 18 החלקים לפי החודש המקראי, והחלק הנוכחי מודגש.
  - 24 השעות ושנתות הדקות.
  - נקודות לזריחה ולשקיעה.
- **כרטיס התאריך:**
  - התאריך הלועזי.
  - התאריך המקראי, יום בשבוע, שנה במחזור ואות.
  - המשמרת. בשבת: יוצאת ונכנסת.
  - מועד, ספירה ושמיטה, כשיש.
  - שער ו-X/דוקה.
  - זריחה ושקיעה, ושם המקום.

## זמן אמת
- האפליקציה היא **רקע חי**, ובזמן שהמסך דולק היא מציירת את עצמה מחדש בכל שנייה.
- המחוגים (24 שעות ודקות) זזים כל הזמן.
- התאריך המקראי מתחלף בדיוק בזריחה, וכך גם החלק של חנוך, השער ושאר הנתונים ברגע שהם משתנים.
- כשהמסך כבוי לא מצויר כלום, ולכן כמעט אין צריכת סוללה.
- One UI לא מאפשרת רקע חי רק במסך הנעילה. לכן האפליקציה בודקת אם הטלפון נעול:
  - **נעול:** שעון חנוך והתאריך.
  - **פתוח (מסך הבית):** רק התמונה שלך. אפשר לשנות את זה בהגדרות.

## בנייה (GitHub עושה את זה)
1. ליצור מאגר חדש ב-GitHub ולהעלות אליו את כל הקבצים, **כולל התיקייה `.github`**.
2. GitHub בונה את ה-APK לבד, בלשונית **Actions**. לוקח כ-3–5 דקות.
3. הקובץ מופיע תחת **Releases**, בשם `Luach364-N.apk`.

## התקנה
1. בטלפון לפתוח את דף ה-Releases ולהוריד את ה-APK.
2. לפתוח את הקובץ. אנדרואיד יבקש לאשר "התקנה ממקור לא ידוע", לאשר.
3. באפליקציה:
   - **בחר תמונת רקע**: אותה תמונה שיש לך היום במסך הנעילה.
   - לכוון את **גובה התוכן**, כדי שלא יתנגש בשעון של סמסונג.
   - **הגדר כרקע**. במסך שנפתח לבחור **"מסך הבית ומסך הנעילה"**.

עובד בכל אנדרואיד 8 ומעלה. כל גרסה חדשה נחתמת באותו מפתח (`app/luach364.keystore`), ולכן מתקינים אותה מעל הקודמת בלי למחוק.
